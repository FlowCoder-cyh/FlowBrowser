## 3. 게이트 동작 (false positive 0)

- **활성 조건**: 최신 user 발화 advisory === `BLOCK_ENTRY` 일 때만. ALLOW_ENTRY / NEUTRAL / 미상 = inert (fail-open).
- **차단**: non-closeout Write/Edit/MultiEdit/NotebookEdit / 새 작업 커밋(feat·fix·refactor·perf) / gh pr create / git push(non-dry-run) / 새 브랜치(checkout -b·switch -c) / dependency mutation(npm install [flags] <pkg>·pnpm·yarn add) / non-closeout 셸 파일 쓰기(Set-Content·Out-File·sed -i, subcommand 단위 타겟 기반).
- **통과 (closeout)**: state.md / handoffs/ / logs/ / eval-results/ / known-issues.md / 사용자 memory + docs·chore·style·ci·test·revert 커밋 + read-only Bash + npm ci·bare install·flag-only. closeout 은 root-anchored (`<root>/.flowset/`, memory 는 `<memoryRoot>/<key>/memory/`).
- **해제**: 매 PreToolUse 호출 transcript 재독 (transcript_path 우선, stale fallback 금지). entry/delegation 발화 박히면 ALLOW_ENTRY → inert.
- **fail-open**: transcript 미발견 / 발화 추출 실패 / 검출 에러 = exit 0.
- **out-of-scope** (guardrails.md 명시): bare `>` redirect / `node -e` 파일쓰기 / cp·mv / MCP write tool.
