### 2.3 5종 표현 (PRD §9.2.1 표 정합)

| 표현 | 결과 | 예시 |
|---|---|---|
| 상대 recent | `{now - duration, now}` | 어제 / 지난주 / 지난달 / 작년 / 오늘 / 그저께 / 이번주 / 이번달 |
| 상대 fix window | `{now - N*step, now - (N-1)*step}` | "3개월 전" → `{now-90d, now-60d}` |
| 상대 older approx | `{target ± margin}` | "6개월 전쯤" / "3개월 전 쯤" → margin 30d (월) / 1년 (년) |
| 절대 YYYY-MM-DD | `{date, date+1d}` (로컬) | "2026-05-01" |
| 절대 YYYY년 N월 | `{month_start, next_month}` (로컬) | "2026년 5월" |

### 2.4 설계 결정

- **모호 표현** ("최근" / "오래된") → null (PRD §9.2.3)
- **다중 표현** → 첫 매치 (가장 빠른 인덱스)
- **"전쯤" 우선 (공백 허용)**: `(\d+)개월 전(?!\s*쯤)` negative lookahead — "전쯤" / "전 쯤" 둘 다 approx 분류
- **시간대**: 절대 표현 로컬 시간 (한국 사용자 직관), 상대 표현 timezone-agnostic ms (PRD §9.2.4 "M5 PoC 결정" 본 PR 에서 결정)
- **pure 함수 + wiring 0**: M5-3 SearchService 가 wiring 책임 — G-013 단계별 PR 전략 §1 정확 준수
