## 1. 진입 게이트 — PoC 2종 통과 (구현 전 검증, CLAUDE.md 30초 PoC + spec §8-2)

Schema v06 spec §8-2/§9 가 T17a 진입 전 별도 PoC 강제. 스크래치 2종 실행 후 삭제 (결과는 회귀에 흡수):

1. **sqlite-vec float[768] vec0 신규 가능** (GATE PASS 6/6) — sqlite-vec **0.1.9** (win32-x64). `float[768]` vec0 테이블이 `float[1024]` 와 동시 생성 가능 / 768 insert+MATCH k-NN+partition key+cosine 정상 / **차원 격리 native 강제** (768 테이블에 1024 벡터 insert 시 sqlite-vec 가 직접 거부: "Expected 768 dimensions but received 1024") / orthogonal cosine distance=1.0 (L2 1.4142 아님).
2. **마이그레이션 메커니즘** (GATE PASS) — **vec0 `ALTER TABLE RENAME` 사용 불가 확정**: throw 없이 "성공" 하나 shadow 테이블(`_rowids`)을 함께 rename 안 해 깨짐(`no such table: vec_pages_1024_rowids`). → `INSERT INTO vec_pages_1024(...) SELECT ... FROM vec_pages` 직접 copy 가능(embedding Buffer 보존). `DROP TABLE vec_pages` 가능. `ALTER TABLE workspaces ADD COLUMN embedding_model TEXT NOT NULL DEFAULT '...' CHECK(...)` 가능(기존 행 DEFAULT 채움 + CHECK 작동). 변환 DDL/DML 단일 transaction commit/rollback 안전(중간 throw → vec_pages 복원 + 컬럼 미추가 + version/sentinel 미박힘).
