## 3. transcript-reader.mjs 핵심 path

### 3.1 source discovery

- `cwdToProjectKey(cwd)`: cwd → projectKey 변환 (Windows `C:\dev\Flowbrowser` → `C--dev-Flowbrowser`, Unix `/home/user/proj` → `-home-user-proj`)
- `discoverTranscriptSource(cwd)`: `~/.claude/projects/<projectKey>/*.jsonl` 중 mtime 최신 파일 박음
- fallback: project dir 없음 / readdir 실패 / jsonl 0 건 — `source: null` + `reason` 박음 (non-blocking)

### 3.2 user 발화 추출

- `extractRecentUserUtterances(sourcePath, n=3)`:
  - JSONL line-by-line 파싱 (JSON.parse 실패 line skip)
  - `obj.type === 'user'` + `obj.isSidechain !== true` + `obj.message?.role === 'user'` + `obj.userType !== 'internal'` filter
  - content 추출: string 직접 / array 의 text block 합산
  - 마지막 N건 반환 (utterances + reason)

### 3.3 advisory 정합 path

- session-start.mjs 안에서 호출 → `detectFinalizationIntent(latest.text)` → advisory 출력
- BLOCK_ENTRY 박힘 시 ⚠️ 경고 + "사용자 명시 선택 박힐 때까지 새 작업 진입 금지"
- ALLOW_ENTRY 박힘 시 ✓ 허용 명시
- transcript source 미발견 / extract 실패 — non-blocking (exit 0, Claude 자체 fallback)
