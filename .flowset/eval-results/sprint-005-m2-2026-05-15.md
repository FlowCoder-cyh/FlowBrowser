### AC-4 glossaryVersion invalidation (S005-T06)
- 임계: 용어 추가/수정/삭제/import 시 version 갱신 → `translationCache.invalidateByGlossaryVersion(prevVersion)` 호출. Settings UI 작업 후 캐시 hit 결과가 사라지는 흐름. 통합 흐름: mutation → version increment → cache invalidate IPC.
- 결과:
  - `GlossaryStore.ts:268-272` `bumpVersion()`이 매 mutation마다 `sha256(Date.now()-length).slice(0,12)`로 새 버전 생성. `add` / `update` / `remove` / `clearAll` / `importTerms` 5종 모두 `bumpVersion` 호출.
  - `services.ts:122-193` 5개 mutation IPC (`glossary:add` / `update` / `remove` / `clear` / `import`) 모두 mutation 직전 `prevVersion = glossaryStore.getVersion()` 저장 → mutation 성공 시 `translationCache.invalidateByGlossaryVersion(prevVersion)` 호출.
  - `services.ts:419` `glossaryVersion = applyGlossary ? glossaryStore.getVersion() : 'default'`, `services.ts:434, 484` 캐시 lookup/store 시 키에 포함 — 버전 변경 시 자동 miss.
  - 단위 테스트 `add bumps version each time` / `update modifies term and bumps version` / `remove deletes and bumps version` / `clearAll removes all and bumps version` 4개로 version 갱신 검증.
- 판정: **Pass**
- 근거: bumpVersion 5종 mutation 100% 적용, IPC 5종이 prevVersion 보존 → invalidateByGlossaryVersion 일관 호출, 캐시 키도 glossaryVersion 포함, 단위 테스트 검증 4개.
