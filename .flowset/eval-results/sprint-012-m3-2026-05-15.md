### A4. Ctrl+Tab 다음 탭 (cycleActiveTabId('next') 사용)

- 임계: Ctrl+Tab → 다음 탭 (wrap 포함), `cycleActiveTabId('next')` 순수 함수 사용 + `switch` + `setActiveTabView`
- 결과 (L1192~1202):
  ```
  label: '다음 탭',
  accelerator: 'CommandOrControl+Tab',
  click: () => {
    const nextId = tabManager.cycleActiveTabId('next')
    if (nextId && nextId !== tabManager.getActiveId()) {
      const ok = tabManager.switch(nextId)
      if (ok) setActiveTabView(nextId)
    }
  }
  ```
- 판정: **Pass**
- 근거: `cycleActiveTabId(direction)` 순수 함수(TabManager.ts:194~202) 호출 후 `nextId !== tabManager.getActiveId()` 가드(L1197)로 단일 탭(자기 자신 반환) 시 불필요 switch 회피. `cycleActiveTabId` 본체는 `(idx + 1) % len` 로직으로 마지막→첫 wrap 자동 처리, AC-3 wrap 요건 만족.
