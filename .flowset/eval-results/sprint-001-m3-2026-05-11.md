## 항목별 채점

### T08 Selection 추출 (수용 기준: AC-4 입력)
- 임계: 웹페이지에서 선택된 텍스트를 안정적으로 main 프로세스로 전달
- 결과: `src/main/index.ts:52-66` — `browserView.webContents.on('context-menu')`에서 `params.selectionText`를 trim하여 빈 선택이면 메뉴 자체를 표시하지 않음. OS 컨텍스트 메뉴(Electron 표준)를 사용해 DOM 직접 주입 없이 selection 획득.
- 판정: **Pass**
- 근거: Electron 공식 API(`context-menu` 이벤트 + `params.selectionText`)는 외부 페이지(sandbox=true)에서도 안전하게 동작하며, 별도 content script 주입이 필요 없음. T08 산출물 위치는 계약상 `src/perception/SelectionExtractor.ts`이지만 동일 책임을 OS 표준 메뉴로 더 간결하게 달성 — 선택의 합리성 확보. 30자 초과 시 ellipsis preview까지 처리 (`index.ts:56`).

### T09 미니 팝업 (TranslationPopup)
- 임계: 4 상태(loading/result/blocked/error), 좌표 anchor, Esc 닫기, 메타 정보(모델/토큰/비용/지연)
- 결과: `TranslationPopup.tsx:3-28`에 `idle | loading | result | blocked | error` 5개 판별 유니언. `useEffect` 두 개로 `popupApi.onShow` / `onResult` 구독 후 cleanup까지 정확히 수행(`:33-77`). Esc 키 글로벌 핸들러 등록/해제(`:79-86`). 위치는 `position: absolute`로 `anchorX/anchorY+URL_BAR_HEIGHT` 사용, `window.innerWidth - 360` clamping으로 우측 잘림 방지(`:90-95`). 메타 줄에 modelUsed / inputTokens+outputTokens / cost(6자리) / durationMs 모두 표시(`:116-119`).
- 판정: **Pass**
- 근거: 계약 4상태 + Esc + anchor + 메타 4종 모두 충족. styles.css의 `.translation-popup` ~ `.popup-error` 11개 클래스가 정의돼 시각 상태 분기 완성(`styles.css:422-511`).

### T10 TranslationEngine 통합
- 임계: `handleContextMenuTranslate`가 `scanWebContentsFields` → `executeTranslateRequest` → mainWindow forward 흐름을 강제
- 결과: `src/main/index.ts:133-170` 흐름 — (1) `popup-show {status:'loading'}` 즉시 전송 → (2) `scanWebContentsFields(webContentsId)` 호출 → (3) `executeTranslateRequest({ providerType:'openai', input:{...selection...}, context:{ url, hasPasswordField, hasCardField } })` → (4) `popup-result` forward. `services.ts:243-322` `executeTranslateRequest`는 `export`되어 내부 직접 호출 + IPC 양쪽 진입점 통일.
- 판정: **Pass**
- 근거: 흐름 순서가 계약과 일치. 분리된 main process 함수로 추출되어 향후 keyboard shortcut / paragraph translation에도 재사용 가능. `requestType: 'selection'`으로 TranslationInput discriminator 명시.

### Privacy Filter 게이트 (G-004)
- 임계: selection 번역 호출 전 password/카드 필드 검사 → `evaluatePrivacy` 통과 시에만 OpenAI 호출
- 결과: `handleContextMenuTranslate`가 `scanWebContentsFields(webContentsId)`를 먼저 호출 (`index.ts:151`), 결과를 `hasPasswordField/hasCardField`로 `executeTranslateRequest.context`에 전달 (`:162-166`). `executeTranslateRequest` 내부 `evaluatePrivacy({ context, text, consent, domains })` 호출 (`services.ts:246-257`), `decision === 'blocked'`이면 provider 호출 없이 `transmissionLogger.recordBlock` + 차단 응답 (`:259-269`). Provider 호출은 차단 통과한 경우에만 도달.
- 판정: **Pass**
- 근거: 우회 경로 없음. context-menu가 IPC 우회로 provider를 직접 호출하지 않고 동일 `executeTranslateRequest` 게이트 통과 강제. 외부 페이지는 `sandbox:true` 유지(`index.ts:42-48`), `WebContentsRegistry.register`로 ID 기반 안전 lookup(`services.ts:378-387`).
