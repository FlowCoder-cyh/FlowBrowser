### AC-3-2 cancelOnTabSwitch=true 시 자동 abort
- 임계: `cancelOnTabSwitch=true` + 진행 중 paragraphs/page 작업 존재 + tab:switch 발생 → 자동으로 `paragraphsAborted` / `pageTranslateAborted` 플래그 set + aborted 이벤트 정상 발송
- 결과: `index.ts:47~48` 두 플래그를 파일 상단 module-level로 이동 (기존 IPC handler 내부 → 상단). `index.ts:178~192` tab:switch handler에 `const prevId = tabManager.getActiveId(); if (prevId !== null && prevId !== id)` 가드 (실제 전환만 처리) + try/catch로 getUserSetting() 호출 + `setting.cancelOnTabSwitch`이면 두 플래그 set. aborted 이벤트 발송 경로는 기존 paragraphs/page 워커가 플래그 폴링 후 'aborted' emit하므로 별도 변경 불필요.
- 판정: **Pass**
- 근거: 플래그 set 동작이 기존 abort IPC와 동일 시멘틱 (paragraphsAborted=true → translateParagraphsImpl 다음 폴링 지점에서 aborted emit). 같은 탭으로 switch 시 noop 처리하여 의도치 않은 abort 회피. UserSettingStore 미로드 try/catch로 초기화 race 방어.
