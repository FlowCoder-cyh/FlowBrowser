### AC-5 URL Bar 동기화 (탭 전환 시 URL/navState 갱신)
- **임계**: 탭 전환 시 활성 탭 URL로 input 갱신, canGoBack/canGoForward는 활성 탭 history 기준, navigate IPC는 활성 탭 view에 적용
- **결과**:
  - `setActiveTabView()` (main/index.ts L246~252): 탭 전환 직후 활성 view의 `getURL()` + `canGoBack()` + `canGoForward()`를 `browser:navigated`로 즉시 broadcast
  - `UrlBar.tsx` L32~37: `browserApi.onNavigated`로 구독 → `setCurrentUrl/setDisplayUrl/setCanGoBack/setCanGoForward` 자동 갱신
  - `createTabView` 내부 `broadcastNav` (L144~155): `tabManager.getActiveId() !== tabId` 가드 → 비활성 탭 navigation은 보내지 않음 (M1 처리, M2 회귀 없음)
  - `browserView` 전역은 `syncBrowserViewRef()` (L40~42)로 활성 탭과 동기화 → 모든 navigate/go-back/go-forward IPC가 활성 탭에 적용
- **판정**: **Pass**
- **근거**: 별도 UrlBar 변경 없이 main의 broadcast 구조 변경(M1)으로 자동 동작. M2에서 회귀 확인 — typecheck/build 모두 PASS, 단위 테스트 213/213 PASS.
