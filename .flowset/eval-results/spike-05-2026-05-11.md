## 항목별 채점

### 1. 모집 채널 / 메시지 / 폼 항목의 실행 가능성

- 임계: 페르소나 4종(A 개발자 / B 강의 시청자 / C 리서치 / 일반)별 실제 접근 가능한 한국어 채널 명시 + 메시지·폼이 즉시 사용 가능한 수준
- 결과:
  - 채널: 페르소나별로 2~5개 채널 명시 (디스콰이엇·인프런·박사과정 슬랙·Untact 등). 모두 실재 한국 커뮤니티/플랫폼.
  - 모집 메시지: 대상·일정·방법·인센티브를 포함한 즉시 발송 가능 템플릿 (8~10줄).
  - 폼 항목: 9개 (이름/연령/직업/시청 빈도/콘텐츠 종류/화상 가능/희망 시간대/녹음 동의/후기 동의) — 페르소나 매핑(직업·시청 빈도·콘텐츠 종류)과 일정 조율(희망 시간대)에 모두 사용 가능.
- 판정: **Pass**
- 근거: PRD 5.3 페르소나 4종 각각에 매핑된 채널이 구체화되어 있고, 모집 메시지·폼이 즉시 사용 수준으로 자기완결적임. P-001 객관성 충족.

### 2. 인센티브 합리성 (예산 대비)

- 임계: 시간당 한국 일반 사용자 인터뷰 보상(통상 1~3만 원/시간) 범위 내 + 후기 공유·베타 등 비현금 가치 결합
- 결과:
  - 60분: 스벅 기프티콘 1만 원 또는 현금 2만 원
  - 30분: 5천 원
  - 후기 공유 옵션: +5천 원 + 베타 1년 무료
  - 베타 6개월 무료 자동 보너스
  - 총 예산 추정 (10명 × 2.5만 평균) ≈ 25만 원
- 판정: **Pass**
- 근거: 한국 UX 리서치 시장 표준 범위 내(시간당 1~2만 원 + 옵션). 비현금 가치(베타 무료권)는 제품과 결합되어 응답자 품질 자가선별 효과도 가짐. 예산 추정 가능하고 합리적.

### 3. 시연 영상 시나리오의 객관성 (A vs B 동등 비교)

- 임계: 동일 원본 / 동일 길이 / 단일 변수(자막 vs 더빙) 차이 + 더빙 측 비교 핸디캡(0.9배·일시정지) 포함으로 응답자 confirmation bias 최소화
- 결과:
  - 동일 원본·동일 길이(30초) 명시
  - A: 자막만, B: 더빙+볼륨 더킹 30%+속도 0.9배+2초 일시정지 1회
  - 더빙(B)에 의도적으로 PRD 14.2 싱크 정책의 가시적 부작용(속도 변화·일시정지)을 인위적으로 노출
- 판정: **Pass**
- 근거: 사용자가 차별점의 단점(영상이 멈춤·느려짐)을 인지한 상태에서 선택하도록 설계됨. PRD 14.2 정책의 실제 부작용을 시연에 반영. "더빙이 무조건 좋다" 식 유도 없음. P-001 객관성 충족.

### 4. 동의서의 법적·윤리 준수 (개인정보 / 녹음 / 후기)

- 임계: 한국 개인정보보호법 기반 (목적·보유기간·제3자 공유·파기·철회권 명시) + 녹음/후기 선택적 동의 분리
- 결과:
  - 인터뷰 진행 정보(일시·방법·시간)
  - 데이터 처리 목적·익명화·60일 이내 파기 명시
  - 녹음/녹화/후기 공유 각각 분리 선택 체크박스
  - 인센티브 명시
  - 중단권·답변 거부권·삭제 요청권(이메일) 명시
- 판정: **Pass**
- 근거: 한국 개인정보보호법(목적·보유·파기·철회) 핵심 요건 모두 충족. 녹음 거부 시 메모 대체 절차도 명시. 다만 KISA 참조 링크가 일반 URL이며 정확한 동의서 가이드 페이지가 아닌 점은 마이너 — 동의서 본문 자체는 자기완결적이라 Pass 유지.

### 5. 일정 템플릿 현실성 (60분 / 30분 분배)

- 임계: 도입·시연·심층질문·마무리 균형 + 30분 단축 시에도 핵심 가설 검증 가능
- 결과:
  - 60분: 도입 5 / 1부 불편 10 / 2부 자막·더빙 15 / 3부 시나리오 10 / 4부 지불 의사 10 / 마무리 10 = 60분

  - 30분 단축본도 가설 1·2·3(더빙 선호·싱크 허용·지불 의사) 모두 커버
- 판정: **Pass**
- 근거: 60분 합계 정확히 60분. 30분 단축본이 핵심 가설(2부·4부)을 우선 배치하고 보조를 압축한 설계가 적절. UX 리서치 일반 권장 시간 분배(도입 10% / 본문 70% / 마무리 20%) 패턴과 일치.
