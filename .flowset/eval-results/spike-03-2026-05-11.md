- 임계: 추가 드라이버 설치 없이 Windows / macOS에서 시스템 오디오 캡처 가능 여부를 1차 출처 기반으로 매트릭스화

### 항목 2. Electron 통합 방식 분석
- 임계: desktopCapturer / electron-audio-loopback / 네이티브 자체 3개 경로 각각의 안정성·전제조건 식별
- 결과:

  - `electron-audio-loopback` — macOS 12.3+ / Windows 10+ / Linux, Electron ≥31.0.1 요구 명시.
  - 네이티브 자체 — WASAPI / ScreenCaptureKit 직접 호출, 제작 비용 트레이드오프 명시.

- 판정: **Pass**
- 근거: 3개 통합 경로 모두 전제조건과 트레이드오프가 명시되었고, electron-audio-loopback npm/GitHub 링크가 참조 섹션에 포함. 선택은 Phase 1 PoC로 보류한다는 결정도 명확.

- 임계: macOS 화면 녹화 권한 = 시스템 오디오 캡처 권한 통합 사실, 사용자 안내 필요성 명시. Windows 권한 분류 명시.
