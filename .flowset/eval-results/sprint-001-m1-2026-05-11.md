### T02 — 메인 프로세스 + WebContentsView 구성

- 임계:
  - BrowserWindow + WebContentsView 또는 BrowserView로 URL 표시
  - preload + contextIsolation + sandbox 보안 (PRD §10.3)
  - 메인 IPC 핸들러 구성
- 결과:
  - `src/main/index.ts`: `BrowserWindow` + 자식 `WebContentsView` 조합. mainWindow는 React UI 로드, browserView는 외부 페이지 로드(Chromium 그대로).
  - 메인 윈도 webPreferences: `preload: join(__dirname, '../preload/index.js')`, `contextIsolation: true`, `nodeIntegration: false`, `sandbox: false` — preload 사용 필요로 sandbox false (관행적, contextIsolation으로 1차 차단)
  - browserView webPreferences: `contextIsolation: true`, `nodeIntegration: false`, **`sandbox: true`** — 외부 페이지가 로드되는 view에는 sandbox 활성. PRD §10.3 정합.
  - IPC: `navigate` / `go-back` / `go-forward` / `reload` / `get-current-url` 5종 등록, 모든 핸들러가 browserView 존재 여부 가드 + try/catch (`navigate`)
  - 윈도 리사이즈 → `updateBrowserViewBounds()` 동기화, `closed` 시 참조 null화
  - 개발/프로덕션 분기: `ELECTRON_RENDERER_URL` 환경변수로 dev URL vs 파일 로드 구분 (electron-vite 표준 패턴)
- 판정: **Pass**
- 근거: BrowserWindow + WebContentsView 구성 정상, 외부 페이지 view sandbox 활성, contextIsolation 활성, nodeIntegration 비활성. navigationHistory API(`canGoBack`/`canGoForward`) 정상 사용. typecheck/build 통과로 컴파일 시점 보안 설정 정합 확정.

### T03 — URL Bar (React 컴포넌트 + 내비게이션 IPC)

- 임계:
  - URL 입력 / 뒤로 / 앞으로 / 새로고침 (PRD §9.1 P0~P1)
  - `src/renderer/UrlBar.tsx`
  - IPC 호출 동작
- 결과:
  - `UrlBar.tsx`: useState로 currentUrl/displayUrl/busy 분리. 입력 폼 submit → `navigate()` → `window.browserApi.navigate(url)`. 뒤로/앞으로/새로고침 각 버튼 → 해당 IPC 호출 후 `refreshUrl()`로 displayUrl 동기화.
  - `normalizeUrl()`: 빈 입력 → google.com, `https?://` 접두 보존, 도메인 형태 → `https://` prepend, 그 외 → `google.com/search?q=…`. 검색어/URL 양쪽 처리.
  - Esc 키 → displayUrl을 currentUrl로 복원 후 blur. 키보드 UX 포함.
  - 첫 렌더 시 `useEffect`로 DEFAULT_URL(`https://www.google.com`) 자동 로드.
  - `preload/index.ts`: `contextBridge.exposeInMainWorld('browserApi', …)` + 5개 메서드 노출, `BrowserApi` 타입 export. `preload/index.d.ts`로 renderer 측 `Window.browserApi` 타입 declaration.
  - `App.tsx`/`main.tsx`/`index.html`: 표준 React 18 StrictMode + createRoot 패턴, CSP 헤더 (`default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self'`) 포함.
  - `styles.css`: URL Bar 60px (메인의 `URL_BAR_HEIGHT = 60`과 정합), nav-btn/url-input/go-btn 다크 테마 스타일.
- 판정: **Pass**
- 근거: 4개 동작(navigate/back/forward/reload) 모두 React 컴포넌트 + IPC 양단 구현, preload contextBridge로 API 노출, 타입 동기화. URL 정규화·키보드 UX 포함. typecheck/build로 양 끝단 타입 정합 확정.
