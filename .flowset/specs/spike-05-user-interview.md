## 목표

핵심 차별점 가설("한국어 TTS 더빙이 자막보다 선호된다") + 지불 의사(BM 입력) 검증.

## 가설

1. 사용자는 영어 영상 시청 시 자막보다 한국어 음성 더빙을 선호한다.
2. 영상이 0.75배 속도가 되거나 잠깐 멈추더라도 더빙을 원한다.
3. 월 4,900~9,900원 가격대에서 유료 사용 의향이 있다.

## 인터뷰 가이드

### 도입 (5분)
- 자기소개 / 평소 영어 콘텐츠 소비 패턴
- 어떤 사이트 / 어떤 영상 / 어떤 빈도

### 1부: 현재 불편 (10분)
1. 영어 영상을 볼 때 가장 불편한 점은?
2. 영어 문서를 볼 때 가장 불편한 점은?
3. 현재 어떤 도구로 해결하고 있는가? (브라우저 번역 / 파파고 / DeepL / 자동 자막 등)
4. 그 도구의 만족도는? 부족한 점은?

### 2부: 자막 vs 더빙 선호 (15분)
1. (시연 영상 30초) 영어 영상에 한국어 자막이 떠 있는 모습 → 평가
2. (시연 영상 30초) 영어 영상에 한국어 더빙이 입혀진 모습 → 평가
3. 둘 중 어느 쪽이 더 좋은가? 왜?
4. 영상이 잠깐 멈추거나 0.75배 속도가 되더라도 더빙을 원하는가?
5. 3~5초 지연(번역 시간)을 허용할 수 있는가?

### 3부: 사용 시나리오 (10분)
1. 어떤 콘텐츠에서 가장 쓰고 싶은가?
   - YouTube 강의
   - 해외 뉴스
   - 개발 문서
   - 영어 인터뷰 / 팟캐스트
   - 영어 드라마 / 영화
2. 데스크톱 vs 모바일 — 주로 어디서 시청?
3. 별도 브라우저(FlowBrowser AI)를 설치해서 쓸 의향이 있는가?

### 4부: 지불 의사 (10분)
1. 무료라면 어떻게 쓰겠는가?
2. 월 **4,900원**이라면 쓸 의향이 있는가? (1~5 척도 + 이유)
3. 월 **9,900원**이라면? (1~5 척도 + 이유)
4. 긴 영상 더빙을 **크레딧 차감 방식**으로 제공하면 쓰겠는가?
5. **BYOK** (자기 API Key 등록) vs **자체 크레딧** 중 무엇이 더 편한가?

### 마무리 (5분)
- 다른 의견 / 추가 기능 요청
- 베타 테스트 참여 의향

## 측정 항목

- 자막 vs 더빙 선호 비율 (몇 명 중 몇 명이 더빙 선호?)
- 0.75배 / 일시정지 허용 비율
- 가격대별 지불 의사 (% / 점수 평균)
- BYOK vs 크레딧 선호
- 콘텐츠 카테고리 분포

## 판정 기준

| 결과 | 판정 | 후속 조치 |
|---|---|---|
| 더빙 선호 ≥ 60% + 4,900원 의향 ≥ 60% | **Pass** | PRD 차별점 가설 확정, 가격 전략 진행 |
| 더빙 선호 30~60% / 가격 의향 30~60% | **Partial** | MVP 1 (웹 번역) 우선 + 더빙은 옵션화 |
| 더빙 선호 < 30% | **Fail** | 차별점 재정의 (단순 번역 품질 vs 다른 축으로 전환) |
