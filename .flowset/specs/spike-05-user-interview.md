# Spike 5 — 사용자 인터뷰 (5~10명)

> **상태: 가이드 보강 완료 (실제 인터뷰 진행은 사용자 작업)**
> 담당: Claude (가이드 작성) + 사용자 (모집·진행·정리)
> 시작일: 2026-05-11
> 종료 목표: 2주 (모집 1주 + 진행 1주)

## 목표

핵심 차별점 가설("한국어 TTS 더빙이 자막보다 선호된다") + 지불 의사(BM 입력) 검증.

## 가설

1. 사용자는 영어 영상 시청 시 자막보다 한국어 음성 더빙을 선호한다.
2. 영상이 0.75배 속도가 되거나 잠깐 멈추더라도 더빙을 원한다.
3. 월 4,900~9,900원 가격대에서 유료 사용 의향이 있다.

## 대상 모집

PRD 5.2 세부 사용자군 균형 모집 (5~10명):

| 페르소나 | 인원 | 모집 채널 (구체화) |
|---|---|---|
| Persona A. 창업가/개발자 | 2~3 | 스타트업 슬랙 / 디스코드 / X(트위터) 개발자 인플루언서 / 디스콰이엇 / 루키톡 |
| Persona B. 영어 강의 시청자 | 2~3 | 인프런·패스트캠퍼스 강의 후기 / 코딩 부트캠프 동문 / 학생 커뮤니티 (캠퍼스픽 등) |
| Persona C. 리서치 사용자 | 1~2 | 박사과정 슬랙 / 학술 트위터 / 대학원생 카카오 오픈채팅 |
| 일반 콘텐츠 소비자 | 1~2 | 지인 / 구글폼 + SNS 광고 / 사용자 인터뷰 모집 플랫폼 (예: Untact) |

## 시연 영상 시나리오 (인터뷰 2부용)

PRD 17.3 30초 데모는 SNS 공유용. 인터뷰는 **자막 vs 더빙 직접 비교용 별도 영상 2개** 필요.

### 영상 A. 자막만 (30초)

- 원본: 영어 YouTube 강의 도입부 30초 (예: TED, Stanford 강의)
- 처리:
  - 영어 음성 그대로
  - 한국어 자막 오버레이 (정확하고 자연스러운 번역)
  - 양방향 자막 토글 안 함 (단방향 한국어만)

### 영상 B. 더빙 + 싱크 제어 (30초)

- 원본: A와 **동일한** 영상
- 처리:
  - 영어 음성 볼륨 30%로 낮춤 (Volume Ducking)
  - 한국어 TTS 출력 (자연스러운 한국어 음성)
  - 영상 재생 속도 조절 (정상 → 0.9배 → 정상 — 인위적 시연)
  - 0~30초 사이 1회 일시정지(2초) 후 재개

### 시연 시 안내

> "지금 같은 영상의 두 가지 버전을 보여드릴게요. A는 자막만, B는 한국어 더빙 + 영상 속도 자동 조절입니다. 두 버전을 보신 후 어느 쪽이 더 좋은지, 왜 그렇게 느꼈는지 알려주세요."

### 제작 도구 (Phase 1 진입 후)

- 자막: 수동 번역 + 자막 편집기 (Subtitle Edit / Aegisub)
- TTS: OpenAI gpt-4o-mini-tts 또는 ElevenLabs Flash v2.5 (Spike 4 결정)
- 영상 편집: DaVinci Resolve / Adobe Premiere / OBS Studio
- 오디오 믹싱: Audacity (Volume Ducking 수동 적용)

## 미해결 → 사용자 진행 항목

본 Spike는 코드 PoC 없음. 사용자가 직접:

1. **모집 폼 생성** (Google Form, 본 spec 항목 기반)
2. **모집 메시지 발송** (위 채널들에)
3. **시연 영상 2개 제작** (Phase 1 진입 시점, TTS Provider 결정 후)
4. **인터뷰 진행** (5~10명, 1시간 또는 30분)
5. **응답 정리** (Google Sheets에 정량 + 정성)
6. **종합 판정** (분석 템플릿 기반)
7. **PRD v0.3 입력** (페르소나 우선순위 / BM / 더빙 우선순위 등)
