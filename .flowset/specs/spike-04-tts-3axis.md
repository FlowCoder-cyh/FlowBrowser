## 측정 시나리오

### 입력 길이별
- 10초 / 30초 / 1분 / 5분 텍스트
- 한국어 평이한 문장 / 강의형 / 대화형

### 측정 항목
- **품질**: 5명 블라인드 평가 (자연스러움 / 발음 / 억양)
- **지연**: 텍스트 입력 → 첫 오디오 출력까지 시간 (cold start / warm)
- **비용**: 1분 한국어 음성 생성 비용 (USD)
- **TTS/원본 길이 비율**: 한국어 TTS 길이 vs 원본 영어 음성 길이
- **동시 처리**: 5/10/20 동시 요청 시 응답 시간 분포

## 판정 기준 (각 Provider별)

| 조건 | 임계 | 비고 |
|---|---|---|
| 품질 평균 | ≥ 3.5 / 5 | 사용자 만족 최저선 |
| 첫 음성 지연 | ≤ 2초 | PRD 14.2 "약간 지연" 임계 |
| 1분 비용 | ≤ $0.05 | 베타 무료 가능 수준 |
| TTS/원본 길이 비율 | 0.9 ~ 1.2 | 너무 짧거나 길면 싱크 깨짐 |

3개 이상 통과 → MVP 후보. 2개 이하 → 보조 또는 제외.
